Poin Kunci & Intuisi

4 Konsep Utama
Binary Search Tree (BST)
O(log n)

Karakteristik invarian: nilai anak kiri < Parent, dan nilai anak kanan > Parent. Pencarian rata-rata O(log n), namun dapat memburuk menjadi O(n) bila pohon condong tak berimbang.

BFS vs DFS pada Graf
Antrean vs Tumpukan

BFS menggunakan antrean (Queue FIFO) untuk penjelajahan level per level (jalur terpendek tanpa bobot). DFS menggunakan tumpukan (Stack LIFO / Rekursi) untuk menelusuri cabang sedalam mungkin sebelum kembali (backtracking).

Dynamic Programming (DP)
Sub-masalah

Dua pilar utama: Optimal Substructure (solusi optimal dibentuk dari solusi sub-masalah optimal) dan Overlapping Subproblems (masalah yang sama dihitung berulang kali sehingga butuh memoization/tabulasi).

Kompleksitas Amortisasi
Dijkstra Heap

Ekstrak simpul minimum membutuhkan O(log V), sedangkan relaksasi sisi total mencapai O((V + E) log V) menggunakan Binary Min-Heap teroptimasi.
